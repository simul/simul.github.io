trueSKY Deployment
==================

For Unreal
------------
Packaging your games
````````````````````

You should be able to package and run your games without issue, as trueSKY Dll's are deployed automatically. The Dlls are located within Project/Plugins/TrueSkyPlugin/Binaries/Simul.


My Sky is black when I Package!
```````````````````````````````
You should not need to adjust anything when packaging, so if you encounter a black sky, firstly you should check the output log for any information regarding trueSKY. If you cannot resolve the issue via the information gained from the output log, get in touch - either via our discord or via the Q&A boards on our website.

Console Deployment
````````````````````
You will need to download the console binaries separately via the website, which you will have to purchase before you have access to them.
