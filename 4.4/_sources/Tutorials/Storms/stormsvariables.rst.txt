Variables
====================

Keyframe
------------
======================================== ===================== ===================
Variable                                 Definition             Value
======================================== ===================== ===================
Strike Duration                          The time each strike   0.1 to 1000
                                         should last, in
                                         (simulated) seconds.
Strike Frequency                         How many strikes per   0.1 to 10
                                         (simulated) second.
Regional                                 Should there be a      Bool
                                         global storm for this
                                         layer, or just within
                                         a specified region.
Wind affects region position             Should the region      Bool
                                         move with the global
                                         wind.
Radius                                   Radius of the Cloud    0.1 to 1000
                                         Region, in Km.
======================================== ===================== ===================

Layer
---------

.. list-table::
   :header-rows: 1
   :widths: 25 60 15

   * - Variable
     - Definition
     - Value
   * - Real time
     - Sets frequency/duration of strikes to real time. If false, then simulation time.
     - Bool
   * - Branches
     - Mean number of branches to generate from each parent.
     - 1 to 12
   * - Branch Angle
     - Mean angle of branching, in degrees from 0 - 90.
     - 0 to 90
   * - Levels
     - Number of levels of branching.
     - 1 to 5
   * - Thickness
     - Thickness of the lightning trunk, in metres.
     - 1 to 100
   * - Min Pixel Width
     - Minimum pixel size for rendering the lightning strikes.
     - 0 to 8
   * - Roughness
     - How rough/smooth to make the lightning branches.
     - 0 to 1
   * - Sheet
     - How much of the lighting should stay within the clouds.
     - 0 to 1
   * - Moion
     - How much a bolt should move/animate during a strike.
     - 0 to 10
   * - Maximum Radiance
     - Maximum radiance of the strikes.
     - 0.1 to 10000
